首先我们来讲讲以下两个概念：

- 系统代理

  Clash 把 Windows 代理设成 `127.0.0.1:7890`。那些会读取系统代理设置的软件（例如 Chrome / Edge），就会把请求交给 Clash，再由 Clash 按规则决定走直连、代理、节点分组等。

  需要注意的是不是所有软件都会使用系统代理。

- 虚拟网卡 / TUN

  Clash 会创建一张虚拟网卡，然后通过路由规则让系统把网络流量送进这个虚拟网卡，再由 Clash 接管。

接着我们来说说系统代理中的，规则、全局、直连 的概念

`规则`：按规则判断。

`全局`：所有进入 Clash 的流量都走当前代理节点。

`直连`：所有进入 Clash 的流量都不走代理，直接访问。
