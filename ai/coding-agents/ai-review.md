# 关于 ai review

在实践中，我往往使用 2 个 AI：一个 ai 写代码，一个 ai 做 code review

这里的 review 我一般不会超过 3 轮，也就是：

- 第一轮：A 写代码，B review A 的代码，然后提出意见，让 A 修复或者反驳。
- 第二轮：B review A 修复的代码，提出意见。（正常情况下到了这里就应该没有什么意见了，可以停了）

如果这个时候要进入第三轮了，那么注意，一定要知道 B 的 review 意见在说什么，看不懂的话就不要继续。否则，接下来的轮次将会变成 2 个 ai 的技术自嗨，完全不受到你的控制。
